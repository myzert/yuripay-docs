## ☕ Dukung Biaya Server & Riset Pengembang

YuriPay dikembangkan dan dirilis secara gratis di bawah lisensi terbuka ISC untuk membantu ribuan merchant dan developer Indonesia menghindari beban potongan biaya payment gateway pihak ketiga (0% gateway fee).

Anda dapat menyisihkan donasi sukarela untuk mendukung kopi dan server riset pengembang:

- **Dukungan Saweria / QRIS / YuriSupport**: Kunjungi [https://yuripay.pages.dev/#support](https://yuripay.pages.dev/#support)
- **Star di GitHub**: Berikan bintang di [https://github.com/myzert/YURIPAY-GOPAY](https://github.com/myzert/YURIPAY-GOPAY)

Dukungan Anda menjaga proyek ini tetap aktif diperbarui mengikuti perubahan API GoBiz terbaru! 🚀
